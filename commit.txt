lattice_flow and ringspec live in imasm_core now; the kernel keeps its doorway

The word instruments were reachable only by booting this kernel, so the host ask
binary could not use them. They move into imasm_core — the crate both repos
already depend on — and what remains here is a re-export plus one-line wrappers
that print what the shared functions return.

insert_sweep_all stays, because it walks this kernel's own program table and the
shared crate has no notion of one. repair_count became pub so it still reaches it.

No behaviour change: cycle, weight, banked, trans and insert print exactly what
they printed before.
