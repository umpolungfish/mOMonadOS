The MiniKernel is eight registers wide, because the layer is CL8NK and imscription writes four things it had nowhere to put.

The register file was four wide, packing pairs of tuple slots into single Belnap values, which drops four of the twelve slots. The four it dropped were R, the adjoint, and S, the one-to-one, together with G and C: exactly the slots that closure and self-reference are stated in. The file is now eight wide, with the recovered slots seeded into R4 and R5.

IMSCRIB in the kernel writes token diversity, self-reference, Frobenius order and dialetheia completeness into R4 through R7. With no such registers the mini evaluator wrote none of them, which is not a simplification of the operation but its deletion; it now computes the same four by self_imscribe on the running program, which is sound because all four are static in the program, and writes them to the same four places. IFIX stores to memory at the address held in R0 rather than folding the store into a register join.

What remains open is whether the witnesses vote or gate. register_scores weights R0 through R3 through a twelve-by-four affinity table, so R4 through R7 are written and unread, and extending the table would mean inventing weights for values that determine tier in the kernel rather than pull on tokens. The two readings are set out as statements in r4r7_ob3ect_context for the Grammar to settle. The context sheet also records a collision the widening introduced: R4 and R5 carry recovered tuple slots until IMSCRIB overwrites them.
