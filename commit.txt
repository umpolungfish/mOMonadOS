qc: gates need no separators

`qc XTT 4` answered "Unknown gate 'XTT'". The spec was split on whitespace and each
token matched whole against H/T/S/X, so a run of gates typed together became one
nonexistent gate name. Nothing about a circuit requires the spaces.

The spec is now read one gate per character. Whitespace is still accepted and skipped,
case is free, and an unrecognised character is named on its own rather than dragging the
whole run into the error. `qc H T S X 4`, `qc HTSX 4` and `qc htsx 4` give the same braid
word, error and length.

The depth followed from the same principle: if gates need no separator, neither does the
count after them. A trailing run of digits with no separate depth token is read as the
depth, so `qc XTT4` and `qc XTT 4` agree.

Usage text updated. It still advertised "Depth 4..12", which stopped being true when the
clamp came out — depth is any positive integer now, and the net stops on its own when it
outgrows the arena.
