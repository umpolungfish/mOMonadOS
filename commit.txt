prooflift on the metal: the verdicts can be booted, not just trusted

The closure-reads-a-proof verdicts were obtained on a host — a lifter walked Lean
proof terms into the twelve, a binary returned the verdict. That is a transcript,
and a transcript has to be taken on faith. This carries the words and asks the
ON-BOARD kernel, the same check::word_verdict that already gates the vita trunk's
speech, so the result is reproducible by booting rather than by believing.

    identity  p -> p         N     no fork: nothing was weighed
    case split, discharged   T     fork, work, fuse
    one branch undischarged  B     a fork left open
    nothing but a claim      B     the claim, never rejoined

Same four verdicts the host auditor gives. No rule was added for proofs: an
undischarged claim reads B because it lifts to a fork with nothing to pair it, and
this kernel already returned B for a branch that never reconverges.

The self-nest — the closure law's own proof, tens of thousands of tokens — is
behind `prooflift nest` rather than in the default report, and the reason is a
finding rather than a convenience. The host auditor returns on that word promptly.
This kernel's ancestry pairing does not scale the same way and did not return
inside ten minutes. Two implementations of one condition, disagreeing in cost by
orders of magnitude on the same input. Recorded here rather than hidden behind a
verb that appears to hang.
