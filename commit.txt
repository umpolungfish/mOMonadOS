jones takes a braid word and nothing else.

The strand count was a required argument that the word already determines:
sigma_k needs k+1 strands, always. Requiring it created a number the caller
could get wrong, and getting it wrong produced a rejection rather than an
answer — so the interface asked for information it held, then refused work when
the two disagreed. Three rounds went into improving that refusal before the
argument itself was the problem.

It is inferred now. `fibqc jones 1 1 1` is the trefoil, `fibqc jones 1 -2 1 -2`
the figure-eight. There is no strand count to mismatch, so the whole error path
is gone rather than better worded.

validate_braid_word stays for callers that fix n themselves, where a
disagreement is still a real fault worth refusing.
