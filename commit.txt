straus reads the right stabiliser set

The rung's second split tested divisors of M for d ≡ −1 (mod r). That is one
sufficient family inside the criterion, not the criterion: r/M = 1/b + 1/c holds
when some u dividing M² has u ≡ −M (mod r). Divisors of M² are strictly more, and
the difference is n = 2521, which the instrument called unreachable and which
rung 23 closes.

The fixed-point rule is why that was worth suspecting rather than accepting. A
congruence test is a conservative action, and conservative operators admit only
one-shot or no-closure — no basin. A value that will not close is therefore never
"almost" closing, so a persistent no-closure points at the stabiliser set being
read, not at the value. It was the set.

Sweep with the criterion right: 5 ≤ n ≤ 20000, 3333 values, none unreached, the
highest rung needed 23.
