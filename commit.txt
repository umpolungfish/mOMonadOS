A theme for the serial surface, and one report wearing it

Colour existed already, as raw SGR escapes written inline across three files.
That is a look frozen into every call site: changing it means finding every
escape, and a report that wants to be quiet has no way to ask.

style.rs holds the palette and it names roles, not colours — frame, heading,
key, value, accent, muted, glyph, and the four Belnap verdicts. The verdicts get
fixed colours on purpose: a verdict that changes colour between reports is a
verdict the reader has to learn again on every screen. Raw escapes appear in
this file and nowhere else.

The macros carry the furniture. head!, foot!, divider!, kv! and verdict_line!
put every report on one width and one key column, so a screen of several
commands reads as one program rather than as several sharing a terminal.
rule_n! repeats a box piece without an allocator, which str::repeat would need.

Colour degrades rather than breaking: `color off` empties every escape and the
alignment is unchanged, because no width computation depends on an escape being
present. A serial line piped into a file gets the glyphs and none of the noise.

fibqc readout wears it first, being the command a new reader is most likely to
run. The reset now lands BEFORE each newline; emitting it after put an escape at
the start of every following line, invisible on a colour terminal and litter in
any captured log. The period prints as a number rather than as Some(4).

Also fixed, and unrelated to the styling: the readout's lattice residual called
f64::round, which is std-only, so the bare-metal target had stopped building.
It uses libm::round now, like every other float call in that file, and the ELF
builds again.
