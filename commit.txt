List every REPL command in the menu, and guard it

The menu is what a user reads to find out what the kernel does, and it had
drifted 33 commands behind the dispatch. sic, d12, d2048, triple, iuft, riemann,
braid-grammar, distance, join, sigma, clay, psm, entropy, mersearch, cycle,
weight, banked, trans, arev, ask, spine, vessel, vita, whoami, ruleset,
absorption, replicative and quit all worked and none were listed.

All 33 added, with descriptions taken from the code rather than invented — most
came from the unreferenced print_help, which had them and never displayed them.
Two new categories carry the ones that had no home: IMASM for the word walks and
Kernel for the utilities.

check_menu_coverage.py fails on any command that is neither listed nor named as
an alias in its primary entry's description, so `d2048 … (alias d2k)` covers d2k
without its own line. Verified in both directions: it passes on the current tree
and fails when a MenuItem is removed.
