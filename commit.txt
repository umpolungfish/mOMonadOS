Accept the grammar-tool names for the QC commands, and list them in the menu

An agent typed `quantum_compile H` and `jones_polynomial AFWD AREV` and got
"Unknown: quantum_compile". Both operations exist — as `fibqc compile` and
`fibqc jones` — so the same thing had two vocabularies and the caller had to know
which surface it was standing on. Both names now work at the top level, and the
jones path says what it wants when handed opcode names instead of integers rather
than failing blankly.

Also added to GRAMMAR_MENU: quantum_compile, jones_polynomial, bg, hqe, dyson,
troq, afdmc, hop, manifold — the arms that worked but were undiscoverable.

Recorded because it cost a rebuild: `fn print_help` in repl.rs has no callers.
The live help is menu.rs::print_help_topic over GRAMMAR_MENU, so nine lines added
to print_help never appeared. It now carries a comment saying so, and
#[allow(dead_code)] rather than a silent warning.
