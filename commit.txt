The kernel computes knot invariants, and says what it cannot see.

jones_polynomial was in the module and reachable from nothing. `fibqc jones`
takes an arbitrary braid and `fibqc knot` runs a small census, so the invariant
these anyons exist to compute is now available from the REPL rather than only
from the Python port. Validated against exact values for the trefoil, its
mirror, the figure-eight and the cinquefoil.

The chirality verdict is decidable from the value alone and necessarily so:
integer coefficients plus t^-1 = conj(t) on the unit circle give
V(K*) = conj(V(K)), so a mirror pair separates exactly when the imaginary part
is nonzero. The report says "not separated at this root" rather than
"amphichiral", because those are different claims and the cinquefoil is the
case that distinguishes them: it is chiral and evaluates real.

When a value comes out at 1 the report names the limitation outright, since
8_19 collapses to the unknot's value under t^5 = 1 and a silent coincidence
there would be read as an identification.

The QC is also raised out of the middle of the README into the header, the
overview, the badges and the phase table. It was documented at the depth of an
implementation note while being the thing the kernel does that nothing else on
bare metal does.
