Restore the hosted build and the proof vehicle

Two builds had been dead and neither said so where I would see it.

src/vox_decode.rs held nothing but the line saying it re-exports the Vox
decoder. c544d09 removed the carried copy in favour of linking the standalone
crate and never wrote the link, so repl.rs asked for vox_decode::Image and
vox_decode::walk against an empty module. The bare target never noticed,
because the vox command compiles only under the hosted feature. So the hosted
build has been broken since that commit, and with it `make ordinals` — the
guard that fails loudly when the canonical ordinals drift from the Lean table.
It was not reporting drift. It was not reporting anything. It now runs, and all
44 values match Lean canonical.

make_proof_vehicle.sh copied p4ramill/Primitives beside p4ramill/Imscribing.
Primitives lives under Imscribing and is carried by the copy above it, so the
stale line failed with cannot stat, and the script is set -e, so the whole
vehicle aborted on it. Removed; the vehicle builds at 4.5M.

Everything now builds: debug, release, bootimage, hosted, the ordinal guard and
the proof vehicle. The four fixed-point commands still answer.
